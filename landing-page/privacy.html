Tabi Privacy Policy

Updated: August 12, 2026


Tabi is a Chrome extension that helps you search and switch between browser tabs, bookmarks, common Chrome pages, web search, and built-in tools from one place. This policy explains what information the extension uses and when data leaves your browser.

Information We Collect

  • Tab metadata: Titles and URLs used locally when you invoke Tabi.
  • Bookmark metadata: Bookmark titles and URLs used locally for search results.
  • Local storage: Recent tab IDs, client ID, and custom tab names used for recent tabs, rate limiting, and persistent tab renaming.
  • AI request context: If you select Ask AI, Tabi sends your prompt plus current tab context, including tab titles, URLs, and tab group names, to the Tabi backend so the AI request can be processed.
  • Uploaded images: If you use Remove Background, the image you choose or paste is sent to the Tabi backend and then to remove.bg to create the background-removed image.
  • Currency conversion queries: If you use currency conversion with the = shortcut, Tabi requests an exchange-rate quote from Yahoo Finance for the currency pair.
  • Screenshot data: If you use Full Page Screenshot, the current page is captured and stitched locally in your browser for download.

We do not collect your personal communications, passwords, or payment information.

How We Use Information

  • Search open tabs, bookmarks, and built-in Chrome destinations.
  • Switch to an existing tab or open the selected destination.
  • Show recent tabs when the search box opens.
  • Remember custom tab names you set.
  • Run local tools such as color picking, QR code generation, word counting, and full-page screenshots.
  • Process explicit Ask AI requests and return browser actions or one-off answers.
  • Process explicit Remove Background requests and return a background-removed image.
  • Fetch exchange-rate data for explicit currency conversion queries.

Data Sharing

We do not sell, rent, or trade your data. Local search happens inside Chrome. Data leaves your browser only when you use features that require an external service:

  • Ask AI: Your prompt and tab context are sent to the Tabi backend and AI provider to produce the requested action or answer.
  • Remove Background: Your selected image is sent to the Tabi backend and remove.bg for processing.
  • Currency Conversion: The requested currency pair is sent to Yahoo Finance to retrieve an exchange rate.
  • Web Search: If you choose a web search result, your query is sent to the selected search engine in the normal way.

Storage & Security

Recent tab IDs and custom tab names remain in your local Chrome extension storage. Tab and bookmark metadata is not sent to a Tabi backend for ordinary search; it is sent only for explicit Ask AI requests. Images are sent only when you explicitly use Remove Background. Screenshots, QR codes, color values, word counts, and regular calculations are processed locally in your browser.

Your Choices

  • You can uninstall the extension at any time to stop data collection.
  • You can clear Chrome’s extension storage to remove locally stored recent-tab data, client ID, and custom tab names.
  • You can avoid Ask AI, Remove Background, Currency Conversion, and Web Search if you do not want those requests sent to external services.
  • Contact us if you have questions or requests regarding your data.
